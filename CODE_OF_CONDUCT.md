# Code of conduct

RunRay is a small project and this page is short on purpose.

Be direct about code and kind to people. Review the change, not the person
who made it. Assume the other person is trying to help, ask before you
conclude, and say so when you were wrong.

Not acceptable anywhere in this project's issues, pull requests,
discussions or commits: personal attacks, harassment, slurs, sexualised
language, publishing someone's private information, or deliberately
derailing a thread. Doing it once earns a warning from a maintainer;
doing it again earns a block.

If something happened that you do not want to raise in public, write to a
maintainer through GitHub. Reports stay between you and the maintainers.
